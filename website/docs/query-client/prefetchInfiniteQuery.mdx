# prefetchInfiniteQuery(...)

:::warning Deprecated in `@tanstack/react-query >= 5.108.1`

Use `api.<service>.<operation>.infiniteQuery(...).catch(() => {})` via [`infiniteQuery(...)`](./infiniteQuery.mdx) instead. `prefetchInfiniteQuery` remains supported when targeting `@tanstack/react-query >= 5.80.0` (`< 5.108.1`), or when deprecations are disabled via `--tanstack-query-deprecations false`.

:::

The method facilitates the fetching of paginated data.
See TanStack [_queryClient.prefetchInfiniteQuery 🌴_](https://tanstack.com/query/latest/docs/reference/QueryClient#queryclientprefetchinfinitequery)
documentation for more details.

```ts
const result = qraft.<service>.<operation>.prefetchInfiniteQuery(
  {
    parameters,
    requestFn,
    baseUrl,
    ...prefetchInfiniteQueryOptions,
  }
);
```

### Arguments

See [fetchInfiniteQuery](fetchInfiniteQuery.mdx) for the list of arguments.

### Returns

`Promise<void>` - a promise that resolves when the query is successfully fetched

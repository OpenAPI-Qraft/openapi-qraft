# getQueryData(...)

The method enables direct access to the `QueryClient` cache to retrieve the data for a specific _Query_.
See the TanStack [_queryClient.getQueryData 🌴_](https://tanstack.com/query/latest/docs/reference/QueryClient#queryclientgetquerydata) documentation.

```ts
const data = api.<service>.<operation>.getQueryData(
  parameters
);
```

## Arguments

1.  `parameters: { path, query, header, body } | QueryKey | void`
    - **Optional** parameters to retrieve the data from the _Query Cache_.
    - For operations generated with `--queryable-write-operations`, query parameters may also include `body`.
      In that mode, `body` is part of the query key and cache identity for query-client methods.
    - Instead of an object with `{ path, query, header, body }`, you can pass a typed `QueryKey` array.

## Returns
The data from the _Query Cache_ for the specific query, strictly-typed ✨

## Example

<Tabs>
  <TabItem value="parameters" label="Parameters">
    ```tsx
    const pet = api.pet.getPetById.getQueryData({
      path: { petId: 123 },
    });

    expect(pet?.id).toEqual(123);
    ```
  </TabItem>
  <TabItem value="query-key" label="QueryKey">
    ```tsx
    const queryKey = api.pet.getPetById.getQueryKey({
      path: { petId: 123 },
    });

    const pet = api.pet.getPetById.getQueryData(queryKey);

    expect(pet?.id).toEqual(123);
    ```
  </TabItem>
</Tabs>
